# ADR-0003: Use BusinessObject instead of NFT terminology

## Status

Accepted

## Context

NFT terminology can be confusing or undesirable in enterprise and project-planning contexts.

## Decision

Use `BusinessObject` as the user-facing and code-facing term for non-fungible ledger-bound domain objects.

## Consequences

- The model keeps NFT-like ownership and transfer semantics.
- Product language becomes more enterprise-friendly.
- Object schemas can be domain-specific.
