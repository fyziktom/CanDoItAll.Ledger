# CanDoItAll.Ledger.AccountApp

Blazor WebAssembly account client for importing local vaults and interacting with an Ledger node.

The app consumes the shared CanDoItAll Components packages and is also published as the Docker account-app image. Keep node URLs, vault identifiers, and optional IPFS endpoints configurable through the documented environment settings.

Build from the repository root with `dotnet build examples/CanDoItAll.Ledger.AccountApp/CanDoItAll.Ledger.AccountApp.csproj`.
