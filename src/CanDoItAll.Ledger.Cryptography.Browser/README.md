# CanDoItAll.Ledger.Cryptography.Browser

Browser-specific implementations for Ledger cryptography and local account-vault persistence.

This project adapts the core cryptography contracts to JavaScript interop and IndexedDB. Keep browser storage and interop concerns here rather than in the platform-neutral cryptography project.

Build from the repository root with `dotnet build src/CanDoItAll.Ledger.Cryptography.Browser/CanDoItAll.Ledger.Cryptography.Browser.csproj`.
