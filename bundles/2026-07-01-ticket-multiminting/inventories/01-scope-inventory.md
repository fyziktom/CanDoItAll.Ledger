# Scope Inventory

## In Scope

- Ticket creation wizard.
- BusinessObject batch request models.
- VENFT app shell event wiring.
- Adapter host sequential batch submission.
- WASM and SSR create-owner alignment.
- Component/unit tests.
- Playwright/browser validation on running AccountApp containers.

## Out Of Scope

- Persistent browser child-vault/subaccount implementation.
- Large-batch resume/retry UI.
- File upload/IPFS changes.
- Non-ticket-specific batch customization beyond generic recipient targeting.
