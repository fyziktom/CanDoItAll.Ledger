# QA Prompt

For each transaction flow, prove: operation is discoverable; available data is selectable; preloaded values are correct; empty/not-found states are explicit; invalid input blocks submit with accessible text; valid input updates review; advanced/raw fields remain usable; no clipping/overflow occurs; desktop/tablet/mobile actions stay reachable. Capture route, viewport, actions, DOM/geometry assertions, screenshot, result, and repair/retest notes.
