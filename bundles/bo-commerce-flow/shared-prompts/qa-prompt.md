# QA Prompt

Use this prompt for validation.

- Confirm every raw note maps to requirements, source changes, tests, and proof.
- Confirm critical manifests include changed-file hashes, failing-first and passing transcripts, source assertions, anti-stub audit, and production behavior artifact matrix when new production records/states are introduced.
- For UI proof, confirm route, viewport, actions, assertions, screenshots, and open-state dialog/menu proof.
- For commerce proof, confirm no duplicate dispatch on repeated refresh, max clone limits are enforced, original sale transfers only once, and receipts/payments link to the correct BO.
- Confirm long descriptions are visible in details and raw state, not only present in a local model.
- Confirm residual risks are explicit and no raw note is silently weakened.
