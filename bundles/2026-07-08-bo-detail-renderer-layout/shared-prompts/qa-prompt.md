# QA Prompt

Large-screen visual review questions:

- Does a no-DataItems event/ticket/payment/purchase/receipt detail avoid the empty DataItems hero?
- Are primary facts readable without opening Ledger details?
- Does the layout use left-side space that was previously empty?
- Is the related BO card visually the same card used in the gallery?
- Does a media BO with DataItems still show the image/asset preview and data item list?
- Are fields clipped, overlapping, or too small?
- Does the screenshot materially match the generated proposal direction in `bundle://evidence/imagegen/bo-detail-layout-proposal.png`?
- Did dockered AccountApp load after rebuild?
